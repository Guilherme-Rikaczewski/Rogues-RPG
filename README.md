# Rogues RPG [![Quality Gate Status](https://sonarcloud.io/api/project_badges/measure?project=Guilherme-Rikaczewski_Rogues-RPG&metric=alert_status)](https://sonarcloud.io/summary/new_code?id=Guilherme-Rikaczewski_Rogues-RPG)

Rogues RPG é um projeto com o objetivo de prestar o serviço de um hub online para RPGs de mesa, para que jogadores possam interagir com as ferramentas adequadas, de modo a oferecer uma experiência completa para os jogadores.

---

## 🎲 Features do sistema
- Repositório online de fichas para RPG de mesa.
- Tabletop personalizavel e interativo em tempo real.
- Fichas automatizadas com sistemas como D&D 5e.
- Gerenciamento completo de grupos de jogo.
